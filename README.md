# AccordPay

**Secure every agreement.**

AccordPay is verified escrow and programmable commerce infrastructure for buyers and sellers. It enables parties to define transaction terms, secure funds, confirm fulfilment, and release or refund payment through a transparent agreement flow.

AccordPay is being built on GIWA Chain and is under active MVP development.

The project is early-stage software. Its smart contracts are not represented as audited or ready for production use.
