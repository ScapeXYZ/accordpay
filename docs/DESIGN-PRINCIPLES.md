# AccordPay Design Principles

## Professional financial technology

AccordPay should feel precise, credible, and purpose-built for moving value. Use disciplined typography, restrained color, consistent spacing, and explicit transaction language. Every screen should help users understand what will happen to their funds.

## Human-designed character

The product should reflect deliberate editorial and interaction choices rather than a generic AI-generated template. Prefer meaningful details, specific language, coherent composition, and a small number of distinctive brand elements. Avoid interchangeable dashboard patterns and decorative clutter.

## Clear hierarchy

Prioritize agreement status, amount, counterparties, terms, and the user's next action. Separate primary decisions from supporting information. Use progressive disclosure for technical details while keeping transaction consequences visible.

## Calm and trustworthy

Use a restrained palette, stable layouts, plain language, and predictable interactions. Confirmation screens must state the action, amount, recipient or outcome, network, and reversibility before a wallet request begins. Urgency should be reserved for genuine risk or deadlines.

## Accessible by default

Target strong color contrast, semantic structure, keyboard navigation, visible focus, descriptive labels, useful error messages, reduced-motion support, and screen-reader-friendly status updates. Never rely on color alone to convey agreement state.

## Responsive across mobile and desktop

Design each workflow for small screens and larger workspaces from the start. Preserve action priority, readable terms, and transaction context at every width. Tables must adapt without hiding critical information, and touch targets must remain comfortable.

## Visual restraint

Avoid excessive gradients, glowing effects, floating crypto coins, robot artwork, and generic blockchain imagery. Motion and decoration must serve comprehension or feedback. Product screens should foreground agreements and people, not speculative-technology symbolism.

## Independent AccordPay identity

Do not copy GIWA's brand identity, visual system, layouts, or voice. AccordPay must remain an independent product built on GIWA Chain. GIWA should appear accurately as a supported network and ecosystem partner, not as AccordPay's owner or parent brand.

Network attribution should be clear but subordinate to AccordPay's product identity. Do not imply endorsement, ownership, or partnership terms beyond what can be verified.
