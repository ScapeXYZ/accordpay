# AccordPay Icon System

This directory is reserved for reviewed icons that are specific to AccordPay and cannot be supplied appropriately by the future approved interface icon library.

The future icon system should:

- Use one coherent outlined style with rounded joins.
- Maintain a consistent 1.75–2px stroke.
- Be optically prepared for 16px, 20px, and 24px use.
- Use clean SVG paths and documented `currentColor` behaviour.
- Remain understandable without colour.
- Include accessible labels at the point of implementation when an icon conveys meaning.
- Avoid duplicating common icons already available in the approved library.
- Avoid coins, shields, padlocks, blockchain cubes, robots, and generic crypto motifs.

No icon assets exist yet. New files require design review, license or provenance documentation, SVG security review, optimization, and rendering tests before production use.
