# AccordPay Brand Assets

This directory contains reviewed, production-ready AccordPay brand artwork and separate design-history folders.

## Approved production mark

**A3 — Controlled Release** was approved by the AccordPay product lead on **July 28, 2026** as the official AccordPay mark.

The mark represents:

- Two independent and balanced transaction parties
- A protected central holding space
- A controlled release path
- Stable settlement

## Production files

- `logo-icon.svg` — official Pine 800 and Pine 600 mark for white and light surfaces.
- `logo-icon-dark.svg` — official white inverse mark for Pine 800 and other approved dark surfaces.
- `logo-icon-light.svg` — single-colour Pine 800 mark for light surfaces.
- `logo-monochrome.svg` — `currentColor` mark for black printing and neutral documents.
- `logo-monochrome-light.svg` — fixed white monochrome mark for dark backgrounds.
- `favicon.svg` — single-colour Pine 800 browser icon based on the approved A3 silhouette.

Use only the file designed for the destination surface. Do not recolour either path arbitrarily, substitute unapproved brand colours, add effects, or modify the geometry.

No vector wordmark exists yet. In product interfaces, the name **AccordPay** will later be rendered as accessible live text beside the icon.

## Design history

- `concepts/` contains the original exploratory concepts.
- `refinements/` contains the Concept A refinement round.

Historical assets are preserved for design provenance and review. They are not production logos and must not be used in metadata, public product identity, or marketing.

All assets must follow `docs/LOGO-SPECIFICATION.md`. Do not add generated placeholders, unlicensed artwork, fake partner marks, or raster files renamed as SVGs.
