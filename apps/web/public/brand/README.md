# AccordPay Brand Assets

This directory is reserved for reviewed, production-ready AccordPay brand artwork.

Planned files:

- `logo.svg` — primary AccordPay logo for standard light-surface use.
- `logo-dark.svg` — approved logo variant for dark branded contexts.
- `logo-light.svg` — reversed light logo for dark backgrounds.
- `logo-icon.svg` — standalone AccordPay mark for compact interface use.
- `favicon.svg` — simplified, small-size-optimized browser icon.

These files do not exist yet. Future assets must follow `docs/LOGO-SPECIFICATION.md`, include documented provenance and approval status, and pass accessibility, optimization, security, and rendering review before use.

Do not add preliminary concepts, generated placeholders, unlicensed artwork, fake partner marks, or raster files renamed as SVGs.
